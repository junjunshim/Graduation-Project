# 회원가입

### 페이지 목적
* 목적 : 서비스를 처음 이용하는 사용자의 이메일과 비밀번호, 이름 등을 통해 새로운 계정을 생성 및 서비스 이용 권한을 부여하기 위한 페이지

## 화면 구성 요소
- 이메일 입력 필드
- 비밀번호 입력 필드
- 비밀번호 확인 필드
- 회원가입 버튼

## 입력값
- email: string, 필수
- password: string, 필수
- confirmPassword: string, 필수

## 버튼 동작
- 회원가입 버튼 클릭 → 회원가입 API 호출

## 출력/표시 정보
- 가입 성공 → 로그인 페이지 이동
- 실패 → 에러 메시지 표시

## 검증 규칙
- 이메일 형식 체크
- 비밀번호 최소 길이
- 비밀번호 일치 여부

## 에러/예외 상황
- 중복 이메일
- 비밀번호 불일치
