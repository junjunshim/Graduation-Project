### [log-engine]
- **제안자**: 심동준
- **핵심 컨셉**: 대규모 웹 서비스에서 발생하는 트래픽 로그를 실시간으로 수집 및 분석하여 대시보드로 시각화하는 실시간 로그 분석 플랫폼
- **왜 이 주제인가? (Motivation)**: 
  - 실시간으로 데이터를 처리하고 즉각적인 대응이 가능한 시스템의 필요성이 높다.
- **핵심 기술 포인트**: 
  - 실시간 스트리밍 데이터 처리 (C++ 기바 로그 생성기를 통해 고성능 데이터 처리)
  - 시각화 대시보드 (React 기반 실시간 차트 및 ui 구현)
  - 로컬 및 클라우드 환경에서도 재현 가능한 구조 설계
- **이걸 만들면 우리는 뭘 배우나?**: 
  - 빅데이터 처리 구조, 데이터 엔지니어링 기초 역량, api와 대시보드 간의 실시간 통신 구조
