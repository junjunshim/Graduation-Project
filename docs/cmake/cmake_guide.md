# ⚙️ cmake 가이드
우리 프로젝트의 경우, cmake를 통해서 소스코드를 빌드하도록 되어있다.

## 1. cmake란?
c/c++ 프로젝트이 빌드 과정을 자동화하고 관리하는 시스템 생성 도구

## 2. 우리 프로젝트에서는...
우리 프로젝트에서는 docker를 통해서 c++ 컴파일에 필요한 도구들을 컨테이너에 자동으로 설치가 된다. 따라서 따로 로컬에 설치하여 사용할 필요는 없다.

필요시 따로 설치하여 작업할 것

해당 프로젝트에서 사용될 cmake 사용 방법은 [cmake_manual.md](.github/docs/cmake/cmake_manual.md)에서 확인
