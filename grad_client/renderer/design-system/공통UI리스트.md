# 공통 UI 리스트

## 1. 공통 기준

| 화면 요소 | 위치 | 현재 다른 점 | 맞출 대상과 기준 |
| :--- | :--- | :--- | :--- |
| 본문 글씨 | 문서 목록, 활동 목록, 업무 설명 | 화면마다 글씨가 조금씩 다름 | 글씨 크기 `0.82rem` |
| 보조 글씨 | 날짜, 작성자, 작은 설명 | 워크스페이스 쪽이 더 작게 보이는 곳이 있음 | 글씨 크기 `0.78rem` |
| 상태 글씨 | 진행 중, 완료, 예정 같은 상태 표시 | 모양은 비슷하지만 안쪽 여백이 다름 | 글씨 크기 `0.72rem` |
| 패널 제목 | 최근 문서, 최근 활동, 업무 보드 제목 | 대시보드가 `1.05rem`, 워크스페이스가 `1.02rem` | 제목 글씨 크기 `1.05rem` |
| 중요한 숫자 | KPI 카드, 요약 카드 | 숫자 크기 표현 방식이 다름 | 숫자 글씨 크기 `1.75rem` |
| 기본 카드/패널 안쪽 여백 | 카드, 목록 박스, 패널 | 워크스페이스는 반응형 값이 섞여 있음 | 안쪽 여백 `1rem` |
| 카드/패널 안 요소 간격 | 카드 안 글씨와 버튼 사이 | 화면마다 간격이 조금 다름 | 요소 사이 간격 `0.9rem` |
| 검색창 높이 | 상단 검색창 | 대시보드가 `2.25rem`, 워크스페이스가 `2.12rem` | 검색창 높이 `2.25rem` |
| 기본 아이콘 버튼 | 알림, 도움말, 더보기 같은 버튼 | 대시보드 상단 버튼이 더 큼 | 버튼 높이와 너비 `2.25rem` |
| 중요한 버튼 | 새 작업, 새 업무 같은 주요 버튼 | 버튼 종류마다 높이가 조금 다름 | 버튼 높이 `2.5rem` |
| 문서/활동 아이콘 | 문서 목록 아이콘, 활동 작성자 아이콘 | 워크스페이스 문서 아이콘이 살짝 작음 | 아이콘 영역 높이와 너비 `1.75rem` |
| 진행률 막대 | 업무 진행률, 요약 카드 진행률 | 대시보드가 `0.36rem`, 워크스페이스가 `0.42rem` | 막대 두께 `0.42rem` |

## 2. 상단 영역

상단 영역은 검색창, 알림 버튼, 도움말 버튼, 프로필 버튼이 있는 화면 맨 위 영역입니다.

| 화면 요소 | 위치 | 현재 다른 점 | 맞출 대상과 기준 |
| :--- | :--- | :--- | :--- |
| 화면 제목 | 대시보드 인사말, 워크스페이스 위치 표시 | 대시보드는 인사말, 워크스페이스는 현재 위치를 보여줌 | 제목 글씨 크기 최대 `1.55rem` |
| 보조 설명 | 워크스페이스 제목 아래 설명 | 대시보드에는 없고 워크스페이스에만 있음 | 설명 글씨 크기 `0.86rem` |
| 검색창 | 상단 오른쪽 검색 입력칸 | 대시보드는 높고, 워크스페이스는 조금 낮음 | 검색창 높이 `2.25rem`, 입력 글씨 크기 `0.82rem` |
| 검색 아이콘 | 검색창 안 돋보기 | 두 화면 모두 비슷함 | 아이콘 크기 `18px` |
| 알림 버튼 | 상단 종 모양 버튼 | 대시보드 버튼이 워크스페이스보다 큼 | 버튼 높이와 너비 `2.25rem`, 아이콘 크기 약 `20px` |
| 도움말 버튼 | 대시보드 상단 물음표 버튼 | 대시보드에만 보임 | 버튼 높이와 너비 `2.25rem`, 아이콘 크기 약 `20px` |
| 프로필 버튼 | 상단 사용자 버튼 | 대시보드는 이름까지 보이고, 워크스페이스는 아이콘만 보임 | 기본 버튼 높이와 너비 `2.25rem`, 이름 포함 버튼 높이 `2.5rem` |

## 3. 카드, 버튼, 글씨, 아이콘

카드는 정보를 담는 작은 박스입니다. 패널은 카드보다 큰 묶음 박스입니다. 배지는 상태를 보여주는 작은 알약 모양 표시입니다. 아바타는 사람을 나타내는 동그란 아이콘입니다.

| 화면 요소 | 위치 | 현재 다른 점 | 맞출 대상과 기준 |
| :--- | :--- | :--- | :--- |
| 요약 카드 | 대시보드 KPI 카드, 워크스페이스 metric 카드 | 대시보드는 낮고, 워크스페이스는 더 높음 | 카드 안쪽 여백 `1rem`, 숫자 글씨 크기 `1.75rem` |
| 요약 카드 제목 | 카드 안 작은 제목 | 대시보드가 `1.1rem`으로 더 큼 | 제목 글씨 크기 `1rem` |
| 큰 패널 | 업무 보드, 문서, 활동 영역 | 워크스페이스는 화면 높이에 따라 여백이 바뀜 | 패널 안쪽 여백 `1rem`, 요소 사이 간격 `0.9rem` |
| 패널 제목 | 최근 문서, 최근 활동 같은 제목 | 워크스페이스가 조금 작음 | 제목 글씨 크기 `1.05rem` |
| 전체 보기 링크 | 전체 보기, 전체 업무 보기 | 높이와 아이콘 크기가 조금 다름 | 링크 높이 `2rem`, 아이콘 크기 `15px`, 글씨 크기 `0.82rem` |
| 상태 배지 | 진행 중, 완료, 예정 표시 | 워크스페이스는 폭이 고정된 곳이 있음 | 배지 글씨 크기 `0.72rem`, 배지 안쪽 여백 `0.3rem 0.5rem` |
| 문서 아이콘 | 최근 문서, 주요 문서 | 워크스페이스가 `1.72rem`으로 조금 작음 | 아이콘 영역 높이와 너비 `1.75rem` |
| 활동 아바타 | 최근 활동 작성자 아이콘 | 아이콘 안 그림 크기가 조금 다름 | 아바타 영역 높이와 너비 `1.75rem`, 내부 아이콘 크기 `15px` |
| 담당자 아이콘 | 업무 카드나 업무 행의 담당자 | 위치마다 크기가 다름 | 작은 담당자 아이콘 영역 `1.45rem`, 활동용 아이콘 영역 `1.75rem` |
| 진행률 막대 | 업무 진행률, 요약 진행률 | 대시보드 막대가 더 얇음 | 막대 두께 `0.42rem` |

## 4. 대시보드와 워크스페이스에서 다르게 보이는 부분

| 화면 요소 | 위치 | 현재 다른 점 | 맞출 대상과 기준 |
| :--- | :--- | :--- | :--- |
| 검색창 | 두 화면 상단 | 대시보드가 더 높고 글씨도 조금 큼 | 검색창 높이 `2.25rem`, 입력 글씨 크기 `0.82rem` |
| 상단 아이콘 버튼 | 알림, 도움말, 프로필 주변 | 대시보드 버튼이 더 큼 | 버튼 높이와 너비 `2.25rem`, 아이콘 크기 약 `20px` |
| 프로필 버튼 | 상단 오른쪽 | 대시보드는 이름 포함, 워크스페이스는 아이콘만 있음 | 기본 버튼 높이와 너비 `2.25rem`, 이름 포함 버튼 높이 `2.5rem` |
| 요약 카드 | 화면 위쪽 숫자 카드 | 카드 높이와 안쪽 여백이 다름 | 카드 안쪽 여백 `1rem`, 숫자 글씨 크기 `1.75rem` |
| 패널 제목 | 업무/문서/활동 박스 제목 | 워크스페이스가 조금 작음 | 제목 글씨 크기 `1.05rem` |
| 상태 배지 | 업무 상태 표시 | 워크스페이스는 폭이 고정된 배지가 있음 | 배지 글씨 크기 `0.72rem`, 배지 안쪽 여백 `0.3rem 0.5rem` |
| 진행률 막대 | 업무 진행률 | 대시보드가 더 얇음 | 막대 두께 `0.42rem` |
| 문서 아이콘 | 문서 목록 | 워크스페이스가 조금 작음 | 아이콘 영역 높이와 너비 `1.75rem` |
| 활동 날짜 | 최근 활동 날짜 | 워크스페이스가 조금 작음 | 날짜 글씨 크기 `0.78rem` |
| 보드와 타임라인 | 업무 보드, 캘린더, 타임라인 | 화면 역할이 달라 모양이 다름 | 페이지별 예외 |
