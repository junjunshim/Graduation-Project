### [2D-simulation-game]
- **제안자**: 심동준
- **핵심 컨셉**: 플레이어가 농장을 운영하며 작물 재배, 채집, npc와의 상호작용을 하여 게임을 진행하는 2d 농장 경영 시뮬레이션 게임
- **왜 이 주제인가? (Motivation)**: 
  - 시간, 자원, 이벤트가 유기적으로 변화하는 게임 시스템을 직접 설계함으로써 게임 개발 전반에 대한 이해를 높이기 위해서 선정
- **핵심 기술 포인트**: 
  - 2d 게임 시스템 설계 (맵 이동, 타일 기반 월드 구조, 시간 흐름)
  - 게임 로직 (작물 성장, 인벤토리 및 아이템 관리 시스템, 상태 변화)
  - 데이터 저장 (게임 진행 상태를 세이브/로드)
- **이걸 만들면 우리는 뭘 배우나?**: 
  - 게임 시스템 기획 및 구조 설계 능력, 플레이어/npc 상호작용 처리 방식, 실제 플레이 가능한 게임을 완성하는 게임 개발 경험
