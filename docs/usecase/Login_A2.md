# Login(로그인)

### 페이지 목적
* 목적 : 접근하는 사용자를 아이디와 비밀번호를 통해 확인하여, 유효하지 않은 사용자의 접근을 차단하는 페이지

## 화면 구성 요소
- 이메일 입력 필드 (Input)
- 비밀번호 입력 필드 (Password Input)
- 로그인 버튼
- 회원가입 이동 링크
- 에러 메시지 영역

## 입력값
email: string, 필수
password: string, 필수

## 버튼 동작
로그인 버튼 클릭 → 로그인 API 호출
회원가입 클릭 → 회원가입 페이지 이동

## 출력/표시 정보
로그인 성공 시 → 대시보드 페이지 이동
로그인 실패 시 → 에러 메시지 표시

## 검증 규칙
이메일 형식 체크
이메일/비밀번호 공백 불가

## 에러/예외 상황
- 입력값 누락
- 이메일 없음
- 비밀번호 불일치
