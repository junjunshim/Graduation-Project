# 비밀번호 재설정 API

로그인하지 않은 사용자가 이메일로 일회용 재설정 링크를 받아 새 비밀번호를 설정하는 API다.
두 엔드포인트 모두 `Authorization` 헤더를 요구하지 않는다.

## 1. 재설정 요청

| Method | URL |
| :--- | :--- |
| POST | `http://{서버 url}/api/users/password-reset/request` |

### Request

```json
{
  "email": "user@example.com"
}
```

| 파라미터 | 타입 | 필수 여부 | 설명 |
| :--- | :--- | :--- | :--- |
| email | String | 필수 | 재설정 메일을 받을 이메일(대소문자·앞뒤 공백 정규화) |

### Response

계정이 존재하든 존재하지 않든, 쿨다운 중이든 동일한 `200` 응답을 반환한다.

```json
{
  "status": "success",
  "message": "입력한 이메일이 등록되어 있다면 재설정 안내를 보냈습니다. 메일이 보이지 않으면 스팸함을 확인해 주세요."
}
```

| 상태 코드 | 의미 |
| :--- | :--- |
| 200 | 요청 접수(계정 존재 여부를 노출하지 않음) |
| 400 | 이메일 누락 또는 형식 오류 |
| 429 | Nginx IP 단위 요청 제한 초과 |
| 500 | 서버 토큰 생성·해시 처리 실패 |

서버는 사용자당 활성 토큰을 하나만 유지한다. 새 요청이 발급되면 이전 링크는 즉시 무효화되고,
사용자 단위 `60초` 쿨다운과 `1시간 3회` 상한이 적용된다.

## 2. 비밀번호 재설정 확인

| Method | URL |
| :--- | :--- |
| POST | `http://{서버 url}/api/users/password-reset/confirm` |

### Request

```json
{
  "token": "64자리_소문자_또는_대문자_16진수",
  "new_password": "NewPassword1!"
}
```

| 파라미터 | 타입 | 필수 여부 | 설명 |
| :--- | :--- | :--- | :--- |
| token | String | 필수 | 메일 링크의 `#token=` 값(64자리 SHA-256 16진수) |
| new_password | String | 필수 | 새 비밀번호(8~64자, 영문·숫자·특수문자 포함) |

### Response

```json
{
  "status": "success",
  "message": "비밀번호가 변경되었습니다. 새 비밀번호로 로그인해 주세요."
}
```

```json
{
  "status": "error",
  "message": "재설정 링크가 유효하지 않거나 만료되었습니다. 재설정을 다시 요청해 주세요."
}
```

| 상태 코드 | 의미 |
| :--- | :--- |
| 200 | 비밀번호 변경 완료 |
| 400 | 토큰 누락·형식 오류·만료·이미 사용됨·비밀번호 정책 위반 |
| 429 | Nginx IP 단위 요청 제한 초과 |
| 500 | DB 처리 실패 |

성공 시 새 비밀번호를 bcrypt 해시로 저장하고, 해당 사용자의 앱 refresh token과 VSCode 확장
refresh token을 모두 삭제한다. 재설정 링크도 한 번 사용하면 다시 사용할 수 없다.

## 3. 링크와 저장 방식

- 메일 링크: `https://axisflow.team/reset-password/#token=<raw-token>`
- 원문 토큰은 메일에만 넣고 DB에는 SHA-256 해시만 저장한다.
- 링크는 30분 후 만료되며, 한 사용자에게 활성 링크 하나만 허용한다.
- `#token=` fragment는 브라우저가 서버로 전송하지 않으므로 Nginx 접근 로그에 남지 않는다.
- 메일 발송에 실패하거나 메일 설정이 비어 있어도 요청 API는 계정 열거를 막기 위해 일반 성공 응답을 유지한다.
