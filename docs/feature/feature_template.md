# 🚀 기능 개발 정의서: [기능 명칭]

## 1. 개요
- **작업자**: @이름
- **관련 이슈**: #이슈번호 (예: #12)
- **기능 요약**: 이 기능이 무엇을 위한 것인지 한 줄로 설명해 주세요.

## 2. 상세 설계
### 2.1 논리 구조 (Logic)
- 백엔드/알고리즘이 어떤 순서로 동작하나요?
- (필요 시) 핵심 클래스 구조나 함수 흐름을 적어주세요.

### 2.2 UI/UX 계획 (Frontend 한정)
- 화면의 어느 위치에 어떤 요소가 추가되나요?
- 사용자 상호작용(버튼 클릭 등) 시 어떤 반응이 일어나나요?

## 3. 의존성 및 변경 사항
- **추가 라이브러리**: 이 기능을 위해 새로 추가한 외부 라이브러리가 있나요?
- **헤더 파일 변경**: `include/` 폴더 내에 새로 추가되거나 수정된 공통 헤더가 있나요?

## 4. 체크리스트 (Self-Check)
- [ ] `include/` 폴더 기준 경로 규칙을 준수했는가? (예: `#include "backend/..."`)
- [ ] 변수명/클래스명 컨벤션을 지켰는가?
- [ ] `build` 폴더에서 정상적으로 컴파일되는가?
- [ ] Docker 환경에서도 실행에 문제가 없는가?

## 5. 테스트 계획
- 이 기능이 정상 작동하는지 확인하기 위해 어떤 테스트를 진행했나요?
