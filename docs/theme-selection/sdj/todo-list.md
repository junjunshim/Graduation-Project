### [todo-list]
- **제안자**: 심동준
- **핵심 컨셉**: 작업들 간의 관계를 중심으로 작업 간의 흐름을 직관적으로 파악할 수 있는 관계 중심 todo-list 관리 프로그램
- **왜 이 주제인가? (Motivation)**: 
  - 작업을 독립적으로 관리하는 todo리스트 프로그램들은 작업간의 관계나 전체 흐름을 파악하기 어렵다. 이런 한계를 극복하는 새로운 방식을 제안
- **핵심 기술 포인트**: 
  - 관계 기반 데이터 모델링 (작업을 노드로 표현)
  - 일정 관계 시각화 (다양한 형태로 작업 흐름을 시각화)
  - 팁 협업 기능 (여러 사용자 간의 작업 공유)
- **이걸 만들면 우리는 뭘 배우나?**: 
  - 그래프 이론(DAG, 위상 정렬)을 실제 서비스에 적용하는 경험, 관계형 데이터 구조 설계 및 상태 관리
