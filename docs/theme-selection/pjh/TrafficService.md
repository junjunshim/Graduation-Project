### [TrafficService]
- **제안자**: 박준현
- **핵심 컨셉**: 공공 포털 api를 활용한 실시간 대중교통 정보 제공 프로그램
- **왜 이 주제인가? (Motivation)**: 
  - 실시간 대중교통 정보를 쉽고 빠르게 확인하여 대부분이 이용하는 대중교통을 보다 편리하게 이용하기 위함.
- **핵심 기술 포인트**: 
  - HTTP Client로 공공 API 호출
  - 주기적 폴링으로 실시간 정보 갱신
  - MySQL 활용으로 정류장/노선 메타데이터 저장
- **이걸 만들면 우리는 뭘 배우나?**: 
  - 소프트웨어 아키텍처 패턴(MVVM) 개념
  - DB, 캐시 구조 설계
  - 공공 API & 데이터 엔지니어링 감각
